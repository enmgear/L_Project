# Tienda Tech

Este es un sitio web simple para una tienda de tecnología. Incluye:

- Menú de navegación
- Sección de inicio con imagen destacada
- Galería de productos
- Integración con pasarela de pago PayPal
- Chat en vivo (simulado)
- Formulario de contacto

## Archivos

- `index.html` - Página principal
- `estilos.css` - Estilos personalizados
- `funciones.js` - Funciones para chat y botones
- `README.md` - Este archivo

## Requisitos

Para visualizar el sitio, solo necesitas un navegador web moderno. No se necesita instalación.

## Pasarela de pago

La integración con PayPal está incluida usando su SDK. La clave de cliente actual está configurada para el entorno sandbox (`client-id=sb`). Para producción, deberás usar tu propia clave.

## Uso

1. Descomprime el archivo `tienda_tech.zip`.
2. Abre `index.html` en tu navegador.
3. ¡Listo para explorar o personalizar!
